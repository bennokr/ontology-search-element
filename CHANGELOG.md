# Changelog

## 0.1.0 — 2026-09-09

- Extract the ontology search UI shared by LinkedBayes and Statlet.
- Add Wikidata, OLS4, CESSDA ELSST, UNESCO, AGROVOC, and HL7 NullFlavor providers.
- Define the neutral `ontology-select` and `ontology-clear` event contract.
- Add Shadow DOM styling, provider configuration, and a compatibility alias for `<ontology-mapper>`.
